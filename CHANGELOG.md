# Changelog

## 0.2.0 - 2026-10-31

### Changed

* **Breaking:** Python 3.11 or newer is now required. Python 3.7–3.10 are
  end-of-life; users on those versions can continue to use 0.1.0.
* Switched packaging from Poetry to [uv](https://docs.astral.sh/uv/)
  (`uv_build` backend, PEP 621 metadata).
* Added classifiers for Python 3.11–3.15.

## 0.1.0 - 2023-03-19

* Initial release, derived from
  [virtualenv-pyenv](https://github.com/un-def/virtualenv-pyenv).
